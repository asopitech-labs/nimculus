# Codex ブリーフ: 意味のある視覚構造へ（行番号・スクロールバー・ベースライン・検索バー）

「対応する要素が存在する」だけでは不十分。**意味的に正しい階層・整列・視覚的な所属関係**を
持たせる。Zed の実装（`references/zed`）と実際の見え方を基準にする。macOS のみ。
`DEVELOPMENT_GUIDELINES.md` 厳守。`nimble clean` 禁止。コミットしない。

## 実機で確認した欠陥

### 1. 行番号がエディタの外へはみ出している（重大）
現状、行番号（例 724〜730）が**エディタ矩形の左外側**に描かれ、ウィンドウ端で数字が切れて
いる。Zed では行番号は**エディタ内のガター**に属し、エディタ矩形の内側で右揃えされ、
決してはみ出さない。
→ ガターをエディタ矩形の**内側**に配置し、エディタの左端＝ガターの左端になるようにする。
　 ガター幅は桁数から算出し、テキスト開始位置はガター幅＋パディングとする。
　 ガター・本文・カーソル・選択・診断・git gutter・ヒットテスト・IME 矩形すべてを、
　 この「エディタ内座標系」で一貫させる。左にはみ出す描画を無くす。

### 2. スクロールバーがオーバーレイになっていない
Zed のスクロールバーは**コンテンツの上に重なる半透明オーバーレイ**で、レイアウト幅を
奪わない。現状 Nimculus はスクロールバー用に領域を予約している疑いがある
（`EditorTextRightInset` などで本文幅を削っている）。
→ スクロールバーを**オーバーレイ描画**にし、本文のレイアウト幅を削らない。
　 表示・非表示でテキストの折返しや行幅が変化しないこと。

### 3. アイコンとフォントのベースラインが揃っていない
ステータスバー・検索バー・タブ・パンくず・パネルヘッダーで、アイコンとテキストの
**縦中心/ベースライン**がばらついている。
→ 各行内で、アイコンは**テキストの光学的中心**に合わせる（SF Symbols は
　 `NSImageSymbolConfiguration` のテキストスタイル連動を使い、フォントメトリクスから
　 中心を出す）。行の高さ・パディングをトークン化し、全バーで同じ規則を使う。

### 4. 検索バーの `0 of 0` が浮いている／トグルの意味が不明
- `0 of 0` は入力欄ともボタン群とも無関係な位置に浮いている。Zed は
  **入力欄の内側（右端）にマッチ数**を置き、テキストと同じベースラインで揃える。
- `Abc` `☰` `{}` `⟳` は意味が伝わらない。Zed は Case sensitive / Whole word / Regex を
  それぞれ明確なアイコンで示し、**トグル状態を背景＋アクセント色**で表す
  （`references/zed/crates/search` の `SearchOption::as_button`）。
- 検索バー全体がエディタ上に無関係に浮いている。Zed は**エディタ上部のツールバー行**として
  収まり、エディタ内容がその下に続く。
→ (a) マッチ数を入力欄内の右端へ移す、(b) トグルを意味の分かるアイコン＋状態表示にする、
　 (c) 検索バーをエディタ上部のツールバーとして正しく所属させる（浮遊させない）。

## 進め方

- 上記 4 点は**視覚的な所属関係と整列**の問題。個々の要素を足すのではなく、
  「エディタ矩形」「ツールバー行」「ステータスバー行」という**コンテナの境界**を定義し、
  その中で子要素を配置・整列する構造にする。
- 余白・行高・アイコンサイズは既存のデザイントークンに集約し、全バーで共有する。

## 検証（必須・ライトとダーク）
```sh
nimble format  > /tmp/nimculus-fmt.log   2>&1
nimble lint    > /tmp/nimculus-lint.log  2>&1 || { tail -n 60 /tmp/nimculus-lint.log; exit 1; }
nimble test    > /tmp/nimculus-test.log  2>&1 || { tail -n 80 /tmp/nimculus-test.log; exit 1; }
nimble build   > /tmp/nimculus-build.log 2>&1 || { tail -n 40 /tmp/nimculus-build.log; exit 1; }
```
- **必ず `open build/macos/Nimculus.app` で起動し、実際に (1) 大きな行番号のファイルを開いて
  行番号がエディタ内に収まっていること、(2) スクロールバー表示時に本文幅が変わらないこと、
  (3) Cmd+F で検索バーを開きマッチ数が入力欄内に収まりトグルの状態が分かること**を確認する。
  新しい `~/Library/Logs/DiagnosticReports/Nimculus-*.ips` が出ないこと。
- ガター座標・ヒットテストの回帰テストを追加する。
- `DESIGN_DECISIONS.md` に記録。`nimble clean` 禁止。コミットしない。
