# UI/UX 移植の完了基準（Definition of Done）

「Zed に対応する要素が存在する」ことは完了条件ではない。以下を**測定して**満たしたときに
その領域の移植を完了とする。基準は Zed の実装（`references/zed`）と、同一条件で撮影した
スクリーンショットの**実測値**で判定する。

## 0. 測定条件（比較の前提）

同一条件でなければ比較は無効。毎回そろえる:

- 同じドキュメント（既定: `DEVELOPMENT_GUIDELINES.md`）
- 同じテーマ（One Light / One Dark の両方を別々に測る）
- 同じカーソル位置・スクロール位置
- 同じ表示状態（Project パネル開、他パネル閉）

比較は `tools/ui_parity.py` で行い、結果は数値で残す。

## 1. 幾何（Geometry）— ピクセル実測で判定

| 指標 | 許容差 | 測り方 |
| --- | --- | --- |
| 行の高さ（buffer line height） | **±1px** | エディタ領域のテキスト行ピッチを検出 |
| ガター幅（行番号領域） | ±2px | 行番号列の左端〜本文左端 |
| 本文左端 x（テキスト開始） | ±2px | 本文グリフの最左位置 |
| タブバー行の高さ | ±2px | 水平境界の検出 |
| パンくず行の高さ | ±2px | 同上 |
| ステータスバー行の高さ | ±2px | 同上 |
| スクロールバー幅 | ±1px | オーバーレイ thumb の実幅 |

**構造条件（0 許容）**
- ガターはエディタ矩形の**内側**に完全に収まり、1px もはみ出さない
- スクロールバーはオーバーレイで、表示/非表示によって本文幅が**1px も変化しない**
- 各行内の要素は同一ベースライン（アイコン中心とテキスト中心の差が **±1px**）

## 2. 配色（Color）— 実ピクセル値で判定

| 対象 | 許容差 | 測り方 |
| --- | --- | --- |
| エディタ背景 | **完全一致**（±0） | 本文領域の無地部分をサンプル |
| ガター背景 | 完全一致 | ガター無地部分 |
| アクティブ行背景 | ±2/255 | カーソル行の無地部分 |
| ステータスバー背景 | ±2/255 | 無地部分 |
| タブバー背景 / アクティブタブ背景 | ±2/255 | 無地部分 |
| 本文前景・syntax 各色 | ±2/255 | グリフのコア画素 |

Zed の値は `assets/themes/one/one.json` を正とし、**実際に描画された画素**が一致すること
（設定に入れただけでは不可）。

## 3. 意味論（Semantics）— 目視ではなく仕様で判定

各コントロールについて次を全て満たす:

1. **所属**: どのコンテナ（エディタ矩形／ツールバー行／ステータスバー行／パネル）に
   属するかが明確で、その境界の内側に配置されている。浮遊しない。
2. **意味**: アイコン単体で機能が推測できる。できない場合はラベルを併記する。
   Zed に対応物があるならその図像的意味（例: Aa = 大小文字）を再現する。
3. **状態**: トグルは ON/OFF が**色と背景**で区別できる。
4. **ツールチップ**: 全ての操作可能要素が説明文を持つ。
5. **生きている**: クリックして何も起きない要素を出さない。
6. **無関係な装飾をしない**: 項目の意味と無関係なアイコンを付けない。

## 4. 完了判定

領域ごとに次をすべて満たしたときに「移植完了」とする:

- [ ] 幾何: 表 1 の全項目が許容差内（構造条件は 0 許容）
- [ ] 配色: 表 2 の全項目が許容差内（ライト・ダーク両方）
- [ ] 意味論: 表 3 の 6 項目を全コントロールが満たす
- [ ] 実機で当該パネル/機能を**操作**してクラッシュしない
- [ ] `nimble format` / `lint` / `test` / `build` が通る
