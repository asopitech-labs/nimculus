# Mixed script sample

M3's completion criteria require Japanese, English, symbols and emoji to be
drawn together on the GPU. A capture of this file shows whether they are.

日本語のテキストと English text を混在させる。記号: → ← ↑ ↓ ± × ÷ ≠ ≤ ≥

Emoji, plain:        🙂 🎉 🚀 ⚡ 🔥 ✅ ❌
Emoji, keycap:       1️⃣ 2️⃣ 3️⃣ #️⃣
Emoji, ZWJ sequence: 👩‍💻 👨‍👩‍👧‍👦 🏳️‍🌈
Emoji with skin tone: 👍🏽 👋🏿 🤝🏻

これらが単色や空白として描かれていたら、polychrome 経路が働いていない。
